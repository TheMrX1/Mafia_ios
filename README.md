# Mafia for iPhone

Атмосферный автономный ведущий для игры в мафию на одном iPhone.

## Что уже реализовано

- спортивная мафия на 10 игроков;
- обычная мафия на 6–16 игроков;
- несколько оценённых по сложности конфигураций ролей;
- объяснение правил до раздачи;
- приватная раздача ролей передачей одного iPhone;
- три темы: неонуар, ар-деко и минимализм;
- полноэкранные авторские фоны для каждой темы;
- отдельные кинематографичные иллюстрации всех семи ролей;
- адаптивная вёрстка для разных размеров iPhone и Dynamic Type;
- edge-to-edge интерфейс без пустых зон вокруг контента;
- компактное раскрытие роли с анимацией, тактильным откликом и полным досье по запросу;
- дневной таймер и выбор сигнала;
- последовательное голосование, подсчёт, ничья и исключение;
- ночная музыка с импортом из приложения «Файлы»;
- ручная отметка выбывших ночью;
- автоматическое определение базовой победы города, мафии или маньяка.

## Запуск

1. Установите Xcode из App Store.
2. Откройте `Mafia.xcodeproj`.
3. Выберите проект `Mafia` → `Signing & Capabilities` → свою Team.
4. При необходимости замените Bundle Identifier `com.laceut.Mafia` на уникальный.
5. Подключите iPhone, разблокируйте его и подтвердите доверие компьютеру.
6. Выберите iPhone в верхней панели Xcode и нажмите Run.
7. Если iOS попросит, включите `Настройки` → `Конфиденциальность и безопасность` → `Режим разработчика`.

Минимальная версия — iOS 17. Код написан на SwiftUI и не использует сторонние зависимости.

## Сборка неподписанного IPA

Открой терминал VS Code в папке проекта и выполни:

```bash
bash ./build-ipa.command
```

Скрипт собирает Release-версию для физического iPhone без подписи, проверяет
наличие исполняемого файла внутри приложения и создаёт файл
`Mafia-unsigned-ДАТА-ВРЕМЯ.ipa` в `~/Downloads`.

Чтобы запускать скрипт двойным кликом в Finder, один раз выполни:

```bash
chmod +x build-ipa.command
```
